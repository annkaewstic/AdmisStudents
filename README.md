# Admission Dashboard

Этот дашборд позволяет быстро и наглядно оценить работу приемной комиссии за 2024 год по факультетам, кафедрам и финансированию (бюджет / договор). Оформление выдержано оттенках синего и зеленого, фон — светло‑серый.

---

## Содержание репозитория

В папке `release` находятся:

- **README.md** — эта документация  
- **app.py** — основной скрипт Dash‑приложения  
- **requirements.txt** — перечень зависимостей  
- **2024 год.csv** — исходный CSV с  необходимыми полями:
  - `Код`
  - `Направление`
  - `Форма обучения`
  - `Факультет`
  - `Кафедра`
  - `Бюджетные места`
  - `Места по договорам` 
 
- **PDF‑отчёты**  
  - _Количество мест на обучение в 2024 году. Очная.pdf_  
  - _Количество мест на обучение в 2024 году. Очно‑заочная.pdf_  
  - _Количество мест на обучение в 2024 году. Заочная.pdf_  

---

## Обзор интерфейса

### Заголовок и описание  
В верхней части отображается крупный заголовок **Работа приемной комиссии** и подзаголовок «Результаты работы приемной комисси за 2024 год».

### Ссылки на PDF  
Ниже располагаются три крупные ссылки на PDF‑отчёты. При наведении текст подчёркивается, при клике каждый документ скачивается.

### Основные графики  

#### Column chart  * 2
Квадратные столбчатые диаграммы, демонстрирующие количество направлений по формам обучения и по источникам финансирования (бюджет/договор).

#### Stacked Bar  
Столбчатая диаграмма, показывающая количество направлений для поступления по факультетам, разделена по кафедрам.

#### Table  
Таблица, выводящая направления по формам обучения и количеству мест.

#### Pie Chart  
Круговая диаграмма, отображающая процент абитуриентов, поступивших на боджетной основе или по договору.

### Итоговая статистика  
Внизу дашборда выводится общее число абитуриентов за 2024 год.
